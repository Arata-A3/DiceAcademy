# DiceAcademy

ファンタジー世界の勇者養成学校（アカデミー）を舞台に、プレイヤーが監督（教官）となってサイコロでマスを進め、止まったマスのイベントや練習で見習い勇者たちを育成していく双六系育成シミュレーションゲーム。育てた勇者パーティーで大会や魔物討伐に挑み、卒業と入学を繰り返しながらアカデミーを強くしていく（野球ではなくファンタジー。既存ゲームの再現ではなく、独自の内容にする）。

---

# 企画書・仕様（草案）

> 「決まったこと」はユーザーと決めた内容。「案」は叩き台で、まだ決まっていない。数値はすべて仮で、遊んで調整する。

## 1. 決まったこと

| 項目 | 内容 |
| --- | --- |
| 動く場所 | ブラウザ（HTML/JavaScript）。スマホでも遊べるようにする |
| 盤の形 | 学年暦の 1 本道に、ところどころ分かれ道がある。進むほど日が経つ |
| サイコロ | 手札の「サイコロ札」から使う目を選び、止まるマスを狙う |
| 戦い | 自動で進むのを観戦する。何が起きているか一目で分かる見せ方にする |
| 長さ | 入学から卒業まで 3 年。学年が入れ替わりながら何年も続けて遊ぶ |
| 生徒の数 | 1 学年 2〜4 人（学園の知名度で変わる） |
| 卒業 | 卒業時に勇者になれるか、どの職業に就くかが決まる |
| 勇者名簿 | 勇者になった生徒は特別な名簿に載り、書き出して別のゲームで使える |

## 2. ゲームの流れ

```
入学式（4月） → 双六で育成 → 行事（大会・討伐・試験） → … → 3月 卒業式・進級 → 次の年へ
```

- 監督の駒は 1 つ。生徒全員がいっしょに 1 年の暦を進む。
- 3 年生は 3 月の卒業式で卒業し、4 月に新入生が入る。
- ゲームに終わりはなく、「勇者を何人出したか」「どの大会で勝ったか」が学園の歴史として残る。（案）

## 3. 盤（学年暦）

### 案
- 1 年 = 約 120 マス（1 マス ≒ 3 日）。サイコロ札の平均で 1 年 約 35 手、20〜30 分。
- 月ごとに区切りがあり、画面上部に今の月と次の行事までのマス数を出す。
- **行事マス**（大会・討伐・試験・入学式・卒業式）は決まった位置にあり、通り過ぎられない（そこで必ず止まる）。
- **分かれ道**は月に 1〜2 回。道ごとに多いマスが違い、合流してまた 1 本道に戻る。
  - 訓練場の道: 練習マスが多い
  - 町の道: 買い物・アルバイト・出会いのマスが多い
  - 森の道: 魔物との小さな戦いや宝のマスが多い（危ないが実入りがよい）

### マスの種類（案）

| マス | 起きること |
| --- | --- |
| 練習 | 指導する生徒を選んで能力を上げる。種類（剣術・魔法・座学など）で上がる能力が違う |
| 休み | 疲れが取れ、やる気が戻る |
| 出来事 | 生徒どうしの出来事や町の事件。選択肢で結果が変わる |
| 買い物 | 装備・道具・サイコロ札を買う |
| 小さな戦い | 弱い魔物と自動戦闘。勝つと経験とお金 |
| 宝 | お金・道具・特別なサイコロ札 |
| けが | 生徒の 1 人が数マスのあいだ練習できない |
| 行事 | 大会・討伐・試験など（4 章） |

## 4. 年間の行事（案）

| 月 | 行事 | 内容 |
| --- | --- | --- |
| 4月 | 入学式 | 新入生が入る。知名度が高いほど人数が多く、素質がよい |
| 6月 | 春の学園対抗戦 | 近くの学園との大会。4 人パーティー |
| 9月 | 魔物討伐遠征 | 決まった魔物の巣を討伐。勝つと知名度とお金 |
| 11月 | 王国武闘会 | いちばん大きな大会。勝つと知名度が大きく上がる |
| 2月 | 卒業試験 | 3 年生だけ。結果が卒業後の進路に効く |
| 3月 | 卒業式 | 進路が決まり、勇者が出れば名簿に載る |

## 5. サイコロ札

### 案
- 手札は 3 枚。1 枚使うと山から 1 枚引く。
- ふつうの札は 1〜6 の目。山には同じ数ずつ入っている。
- 特別な札（宝・買い物で手に入る）
  - 好きな目: 1〜6 から選べる
  - 戻る: 書かれた数だけ戻る（行事の前に練習を稼ぐ）
  - 倍: 目が 2 倍
- 次の 1〜6 マス先に何があるかは見えるので、手札と見比べて狙う。

## 6. 生徒（見習い勇者）

### 能力（案）

| 能力 | 主に効くところ |
| --- | --- |
| 力 | 攻撃の強さ |
| 守り | 受けるダメージを減らす |
| 素早さ | 行動の順番、よける |
| 魔力 | 魔法の強さ |
| 知恵 | 技を覚える、作戦の効き |
| 心 | 勇者になれるか、ピンチに強い |

- ほかに **体力**（戦いの HP）、**疲れ**（たまるとけがしやすい）、**やる気**（練習の伸びに効く）を持つ。
- 生徒ごとに **素質**（伸びやすい能力）と **性格**（出来事での反応）がある。
- 練習マスでは 1〜2 人を選んで指導する。選ばれなかった生徒も少しだけ伸びる（自主練）。

### 卒業後の進路（案）
- 能力と実績（大会・討伐の成績）から、就ける職業が決まる。
  - 戦士 / 騎士 / 魔法使い / 僧侶 / 狩人 / 盗賊 など
- 心と実績が十分で、学園の知名度が足りていれば **勇者** に認定される。
- 勇者になれなかった生徒も、進路は学園の歴史に残る。

## 7. 戦い

- 自動で進み、監督はパーティー（4 人）の編成と **作戦** だけを決める。
  - 作戦（案）: 攻める / ばらんす / 守る / 魔法中心
- 分かりやすさのために（案）
  - 1 回の行動を 1 行で見せる（「アレン の 斬りつけ！ スライム に 12」）
  - 敵味方の体力をバーで出し、ダメージの数字を浮かせる
  - 早送りと結果だけ見るボタンを付ける
  - 終わったら、活躍した生徒と伸びた能力をまとめて出す

## 8. 学園

- **知名度**: 大会・討伐の成績で上がる。入学者の人数（2〜4 人）と素質、勇者認定の通りやすさに効く。
- **お金**: 買い物・設備に使う。（案）
- **設備**（案）: 訓練場・図書館・医務室などを建て、練習の伸びや休みの効きを強くする。

## 9. 勇者名簿と書き出し

- 勇者になった生徒は「勇者名簿」に載り、いつでも見られる。
- 名簿の勇者を 1 人ずつ、または全員分、ファイル（JSON）に書き出せる。（案）
  - 名前・職業・能力・覚えた技・実績・卒業年・学園名・書き出した形式の版
  - 別のゲームで読み込めるよう、形式に版を付けて決めておく。

## 10. セーブ

- ブラウザの中（localStorage）に自動で保存する。月が変わるたび、行事の前後に保存。（案）
- 書き出し・読み込みでバックアップできる。（案）
