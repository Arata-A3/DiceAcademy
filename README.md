# ダイスアカデミー

（リポジトリ名: DiceAcademy）

ファンタジー世界の勇者養成学校（アカデミー）を舞台に、プレイヤーが監督（教官）となってサイコロでマスを進め、止まったマスのイベントや練習で見習い勇者たちを育成していく双六系育成シミュレーションゲーム。育てた勇者パーティーで大会や魔物討伐に挑み、卒業と入学を繰り返しながらアカデミーを強くしていく（野球ではなくファンタジー。既存ゲームの再現ではなく、独自の内容にする）。

## 遊ぶ

- 公開ページ: https://arata-a3.github.io/DiceAcademy/
- 今の版: v0.4（暦を進めて生徒を育て、戦いと大会に挑み、卒業と進級をくり返して何年も続けられる）。画面の右下の版を押すと、変更の記録が見られる。

### 遊び方（v0.4）

1. 下の手札からサイコロ札を選ぶと、止まる日が暦の帯に「ここ」と出る。もう一度押すか「進む」で進む。
2. 1 マス = 1 日。止まったマスの出来事が起きる（練習・休み・出来事・買い物・宝・けが）。行事の日は通り過ぎられない。
3. 練習のマスでは、「能力を伸ばす」か「技を練習する」かを選び、指導する生徒を 2 人まで選ぶ。疲れがたまるとけがをしやすい。技は同じ種類の練習を 3 回ほど受けると覚える。
4. 戦いのマスに止まったら、4 人と作戦を選んで戦う。大会の日は、個人戦なら学校代表を 1 人、団体戦なら 4 人を選んで勝ち抜き戦に出る。
5. 戦いは自動で進む。手札の札を 1 枚選んで、監督の切り札（立て直し・総攻撃・守る）を 1 回だけ出せる（札の目が大きいほど強い）。「早送り」「結果だけ」も使える。
6. 分かれ道が近づくと、帯の下で道を選べる。
7. 特別な札（好きな目・大股・じっくり・予定変更）は宝や買い物で手に入る。
8. 生徒を押すと 16 の能力（段階つき）・職業の適性・覚えた技が見られる。右上のボタンで月のカレンダー、学園の歴史、設定（明るさ・やり直し）を開ける。
9. 3 月 20 日の卒業式で 3 年生が卒業する。適性が基準（115）を超えた職業の中から、進む道を選ぶ（どれも届かなければ、いちばん向いている職業になる）。
10. 3 月 31 日の修了式で 1 年が終わり、みんな 1 つ上の学年になる。次の日は 4 月 1 日の入学式で、暦は新しく作り直される。

> 「決まったこと」はユーザーと決めた内容。「案」は叩き台で、まだ決まっていない。数値はすべて仮で、遊んで調整する。

## 2. ゲームの流れ

```
入学式（4月） → 双六で育成 → 行事（大会・討伐・試験） → … → 3月 卒業式・進級 → 次の年へ
```

- 監督の駒は 1 つ。生徒全員がいっしょに 1 年の暦を進む。
- 3 年生は 3 月の卒業式で卒業し、4 月に新入生が入る。
- ゲームに終わりはなく、「勇者を何人出したか」「どの大会で勝ったか」が学園の歴史として残る。（案）

## 3. 盤（学年暦）

### 決まったこと
- 1 マス = 1 日。1 年 = 365 マス（4 月 1 日から翌年 3 月 31 日）。
  - 札の目の平均は 3.5 なので、1 年で約 100 手、3 年で約 300 手。その分マスの出来事を多くし、じっくり遊ぶ形にする。
  - 札で 5 進むと 5 日たつ。止まったマスの出来事だけが起きる。
- **分かれ道**は短い寄り道で、月に 1〜2 回。数マス先で合流し、どの道も長さ（日数）は同じ。

### 案
- 画面上部に今日の日付と、次の行事まであと何日かを出す。
- **行事マス**（大会・試験・入学式・卒業式）は決まった日にあり、通り過ぎられない（そこで必ず止まる）。
- **討伐マス**は討伐の依頼が来たときだけ盤に出る（4 章）。
- 分かれ道の種類
  - 訓練場の道: 練習マスが多い
  - 町の道: 買い物・アルバイト・出会いのマスが多い
  - 森の道: 魔物との小さな戦いや宝のマスが多い（危ないが実入りがよい）

### マスの種類（案）

| マス | 起きること |
| --- | --- |
| 練習 | 指導する生徒を選んで能力を上げる。種類（剣術・魔法・座学など）で上がる能力が違う |
| 休み | 疲れが取れ、やる気が戻る |
| 出来事 | 生徒どうしの出来事や町の事件。選択肢で結果が変わる |
| 買い物 | 装備・道具・サイコロ札を買う |
| 小さな戦い | 弱い魔物と自動戦闘。勝つと経験とお金 |
| 宝 | お金・道具・特別なサイコロ札 |
| けが | 生徒の 1 人が数マスのあいだ練習できない |
| 行事 | 大会・討伐・試験など（4 章） |

### 画面（決まったこと）
- ふだんは **横に流れる暦の帯** で、今日から先の日を横一列に見せる。その下に生徒、いちばん下に手札を置く。
- ボタンで **月のカレンダー** を開き、その月の予定（行事・分かれ道・討伐の期限）を見られる。
- マスの種類は色とアイコン（SVG）で分ける（案: 練習 青、休み 緑、出来事 橙、買い物 紫、戦い 赤、宝 金、行事 黒）。

## 4. 行事

### 決まったこと
- 大会は種類を多くする。団体戦や、特定の職業が有利な大会（戦士の大会・魔法使いの大会など）がある。
- 職業が有利な大会でも、ほかの職業の生徒も出られる（不利なだけ）。
- 魔物討伐は決まった時期の行事ではなく、出来事として起きる。年によって回数が違う。

### 決まった時期の行事（案）

| 月 | 行事 | 内容 |
| --- | --- | --- |
| 4月 | 入学式 | 新入生が入る。知名度が高いほど人数が多く、素質がよい |
| 2月 | 卒業試験 | 3 年生だけ。結果が実績になる（まだ入れていない） |
| 3月20日 | 卒業式 | 3 年生が卒業し、職業が決まる（決まったこと。勇者の認定はまだ入れていない） |
| 3月31日 | 修了式 | 1 年が終わり、進級する。次の年の暦は作り直す（決まったこと） |

### 大会（案）

1 年に 4〜5 回、暦の決まった日にある。止まらずに通り過ぎられない。

| 大会 | 形 | 有利な職業・決まり |
| --- | --- | --- |
| 新人戦（5月） | 個人戦。1 年生だけ | なし |
| 剣技大会（7月） | 個人戦 | 物理のダメージが上がり、魔法は下がる（戦士・騎士・盗賊が有利） |
| 魔導大会（10月） | 個人戦 | 魔法のダメージが上がり、物理は下がる（魔法使い・僧侶が有利） |
| 学園対抗戦（6月・12月） | 団体戦。4 人パーティー | なし |
| 王国武闘会（1月） | 団体戦。前の大会で勝った学園だけ出られる | なし。いちばん知名度が上がる |

- 大会は勝ち抜き（トーナメント）。勝つほど実績と知名度が上がる。
- 個人戦は 1 学園から何人でも出られる。出すほど疲れがたまる。

### 魔物討伐（案）

- 双六の「出来事」マスや、町の道の掲示板で **討伐の依頼** が届く。
- 依頼には期限（例: 20 日以内）があり、期限までに盤に出る **討伐マス** に止まると挑める。逃すと依頼は消え、知名度が少し下がる。
- 1 年に 0〜3 回くらい。知名度が高いほど、難しくて実入りのよい依頼が来やすい。
- 難しい依頼ほど、名簿の勇者を助っ人に呼ばないと厳しい（9 章）。

## 5. サイコロ札

### 決まったこと
- 手札の枚数は学園の知名度で決まる。知名度が上がると増え、下がると減ることもある。
- 「戻る」札は入れない（1 マス = 1 日なので、日付が戻るのはおかしい）。
- 特別な札は次の 4 つ。

| 札 | 効果 |
| --- | --- |
| 好きな目 | 1〜6 から好きな目を選んで進む |
| 大股 | 目が 2 倍（日が早く進む） |
| じっくり | 書かれた目だけ進み、止まったマスの効果が 2 倍（時間をかけて取り組む） |
| 予定変更 | 先のマスを 1 つ、好きな種類（練習・休みなど）に変える（その日の予定を入れ替える）。行事マスは変えられない |

### 案
- 手札は知名度に応じて 3〜5 枚。1 枚使うと山から 1 枚引く。
- ふつうの札は 1〜6 の目。山には同じ数ずつ入っている。
- 特別な札は宝・買い物・出来事で手に入る。
- 6 マス先まで何があるかは見えるので、手札と見比べて狙う。
- 戦いの切り札にもサイコロ札を使う（7 章）。

## 6. 生徒（見習い勇者）

### 能力（決まったこと: LoL を参考にした次の 16 個）

| 能力 | 主に効くところ |
| --- | --- |
| 体力 | 戦いの HP。0 で倒れる |
| マナ | 技を使うための量 |
| 攻撃力 | 通常攻撃と物理の技の強さ |
| 魔力 | 魔法の技の強さ |
| 物理防御 | 物理ダメージを減らす |
| 魔法防御 | 魔法ダメージを減らす |
| 攻撃速度 | 通常攻撃の回数 |
| 移動速度 | 行動の順番、よける |
| スキルヘイスト | 技を使ったあと、次に使えるまでが短くなる |
| クリティカル率 | 通常攻撃が大きく当たる確率 |
| クリティカルダメージ倍率 | 会心のときのダメージの倍率 |
| 物理防御貫通率・魔法防御貫通率 | 相手の防御を割合で無視する |
| 物理防御貫通力・魔法防御貫通力（名称仮） | 相手の防御を決まった量だけ減らす |
| 行動妨害耐性 | 気絶・足止めなどの時間を縮める |

#### 能力の種類（決まったこと）

- **割合の能力**（クリティカル率・物理防御貫通率・魔法防御貫通率・行動妨害耐性）は % で表し、100% まで上がる。100% を超えた分は次のように変える。

| 能力 | 100% を超えた分 |
| --- | --- |
| クリティカル率 | 超えた 1% ごとに、クリティカルダメージ倍率 +1%（案） |
| 行動妨害耐性 | 超えた 1% ごとに、魔法防御 +3（案） |
| 物理・魔法防御貫通率 | 超えた分を持ち続け、その種類の攻撃のダメージを、超えた 1% ごとに +1% する（案。`PEN_OVER_RATE`）。「100%（+12.4%）」の形で表示する |

- **定数の能力**（ほかの 12 個。クリティカルダメージ倍率と貫通力も含む）は上限がない。目安として **段階**（E・D・C・B・A・S）を数値の横に出す。棒は今の段階の中での進み具合を表す。
  - 段階の目安（案）: ふつうの能力は D 60・C 100・B 150・A 220・S 320。クリティカルダメージ倍率は D 160%・C 175%・B 195%・A 220%・S 260%。貫通力は D 6・C 12・B 22・A 36・S 55。
  - 試算では、入学時はほぼ E、卒業するころの 3 年生はふつうの能力が C くらい。

#### 能力の詳しい働き（案。数値は仮）

戦いは「行動ゲージ」がたまった者から動く形にする（7 章）。ふつうの能力は入学時 20〜60 くらい。

| 能力 | 戦いでの働き | 伸ばす練習 |
| --- | --- | --- |
| 体力 | HP の最大値。0 になるとその戦いでは倒れて動けない | 走り込み・盾の構え |
| マナ | 技を使うたびに減る。足りないと通常攻撃だけになる。毎行動で少し戻る | 魔法の授業・座学 |
| 攻撃力 | 通常攻撃と物理の技のダメージの元になる | 剣術・素振り |
| 魔力 | 魔法の技のダメージと、回復の量の元になる | 魔法の授業 |
| 物理防御 | 物理ダメージを減らす。ダメージ × 100 ÷（100 + 防御 × 0.5）。200 で半分 | 盾の構え |
| 魔法防御 | 魔法ダメージを同じ式で減らす | 結界の授業・精神修行 |
| 攻撃速度 | 行動ゲージのたまる速さ。高いほど通常攻撃の回数が増える | 素振り |
| 移動速度 | 最初に誰から動くかと、攻撃をよける確率（最大 30% くらい） | 走り込み |
| スキルヘイスト | 技を使ったあと、また使えるようになるまでの待ちを縮める（100 で待ちが半分） | 座学 |
| クリティカル率 | 通常攻撃が会心になる確率 | 急所を狙う練習 |
| クリティカルダメージ倍率 | 会心のダメージの倍率。入学時 150% くらい | 急所を狙う練習 |
| 防御貫通率（物理・魔法） | 相手の防御を、この割合だけ無いものとして計算する | 実戦形式 |
| 防御貫通力（物理・魔法） | 割合で減らしたあとの防御から、この値を引く | 実戦形式 |
| 行動妨害耐性 | 気絶・足止め・眠りなどの長さを縮める（100% で効かない） | 精神修行 |

- 防御の計算（決まったこと）: 実際の防御 = 防御 ×（1 − 貫通率）− 貫通力。割ってから引く順。
  - 貫通力が防御を引き切って余った分は、ダメージを増やす。余り 1 ごとに +0.5%（案。`LET_OVER_RATE`）。
  - 例（防御 200 の相手に攻撃力 100）: 貫通なし 50、貫通率 50% で 67、貫通率 50% と貫通力 50 で 80、貫通率 100% で 100、貫通率 100% と貫通力 100 で 150、貫通率 120% で 120。
- 覚える技は職業の希望と能力で決まり、技ごとに使うマナと待ちの長さがある。（案）

- 能力のほかに **疲れ**（たまるとけがしやすい）、**やる気**（練習の伸びに効く）を持つ。（案）
- 生徒ごとに **素質**（伸びやすい能力）と **性格**（出来事での反応）がある。（案）
- 練習マスでは 1〜2 人を選んで指導する。選ばれなかった生徒も少しだけ伸びる（自主練）。（案）

### 職業（決まったこと: 入学時に希望を出し、卒業で決まる）

- 入学時に「希望の道」を持って入ってくる。
- 在学中の育ち方で、卒業時に職業が決まる。希望どおりにならないこともある。
- 決め方（決まったこと）: 職業ごとに **適性** を出し、**基準を超えた職業の中から監督が選ぶ**。どれも基準に届かなければ、いちばん適性の高い職業になる。
  - 適性 = その職業で見る能力の平均 ÷ その生徒の 16 の能力の平均 × 100（100 がふつう）。大きさの違う能力（割合の能力・クリティカルダメージ倍率・貫通力）は、ほかと同じくらいの大きさにしてから比べる（案。`STATS` の `score`）。
  - 基準は 115（案。`APT_LINE`）。試算では、希望の職業を選べる生徒が約 82%、2 つ以上から選べる生徒が約 42%、どれも届かない生徒が約 9%。
  - 卒業生は「学園の歴史」に、卒業した年・職業・希望・総合・大会の勝ちと一緒に残る。毎年の大会の結果も残る。
- 職業は次の 6 つ（決まったこと）と、決まるときに見る能力

| 職業 | 見る能力 |
| --- | --- |
| 戦士 | 攻撃力・体力 |
| 騎士 | 物理防御・魔法防御・体力 |
| 魔法使い | 魔力・マナ・スキルヘイスト |
| 僧侶 | 魔力・魔法防御・マナ（味方を回復） |
| 狩人 | 攻撃速度・クリティカル率・クリティカルダメージ倍率 |
| 盗賊 | 移動速度・物理防御貫通率・物理防御貫通力 |

### 勇者（決まったこと: 職業とは別の称号。実績で決まる）

- どの職業でも、実績が十分なら「勇者」に認定される（例: 勇者・魔法使い）。
- 実績に数える候補（案）: 大会での勝ち・優勝、魔物討伐の成功、卒業試験の成績、大事な出来事での活躍
- 勇者になれなかった生徒も、進路は学園の歴史に残る。（案）

## 7. 戦い

### 決まったこと
- 自動で進む **行動ゲージ制**。ゲージがたまった者から動き、速い者は何度も動ける。
- 監督は戦いの前に編成と作戦を決め、戦いの最中に **監督の切り札** を使える。
- 何が起きているかを分かりやすく見せる。

### 進み方（案）
- 全員の行動ゲージが攻撃速度に応じてたまり、満タンになった者が 1 回動く。始めのゲージは移動速度で決まる。
- 動くとき、技が使えれば（マナが足り、待ちが終わっていれば）技を使い、使えなければ通常攻撃。
- 誰を狙うかと技を使うかは、作戦で変わる。
  - 作戦: 攻める / ばらんす / 守る / 魔法中心

### 技（決まったこと）
- 技は能力とは別に、練習で覚える。練習のマスで「能力を伸ばす」か「技を練習する」かを選べる（どちらで強くするかを選ぶ楽しさ）。
- 覚えた技はすべて戦いで使える。
- 案: 練習の種類ごとに 2 つずつ、順番に覚える（全 20 種）。同じ種類の練習を 3 回ほど受けると 1 つ覚える。2・3 年生は希望の職業の系統の技を 1 つ持って始まる。

### 監督の切り札（案）
- 1 戦に 1 回、手札のサイコロ札を 1 枚使って入れる。使った札は双六で使えなくなる（引き直す）。
- 札の目が大きいほど効果が強い。
  - 立て直し: 味方全員の体力を回復
  - 総攻撃: 全員のゲージを満タンにする
  - 守りを固める: しばらく受けるダメージを減らす
- 大きい目の札を切り札に使うか、双六で使うかが悩みどころになる。

### 画面（決まったこと）
- 味方（生徒 4 人＋助っ人）が左、敵が右に向かい合う。
- 上の段に「次に動く順」を顔の列で並べ、誰がいつ動くか一目で分かるようにする。
- 各自に体力・マナ・行動ゲージのバーを出し、ダメージの数字を浮かせる（会心は色を変える）。
- 下に記録を数行出す。いちばん新しい行を目立たせる（「アレン の 斬りつけ！ 会心！ ガーゴイル に 48」）。
- いちばん下に手札と切り札のボタンを置く。
- 早送りと、結果だけ見るボタンを付ける。
- 終わったら、活躍した生徒と伸びた能力をまとめて出す。（案）

## 8. 学園

- **知名度**: 大会・討伐の成績で上がる。入学者の人数（2〜4 人）と素質に効く。勇者になれるかには効かない（勇者は実績だけで決める）。
- **お金**: 買い物・設備に使う。（案）
- **設備**（案）: 訓練場・図書館・医務室などを建て、練習の伸びや休みの効きを強くする。

## 9. 勇者名簿

- 勇者になった生徒は「勇者名簿」に載り、いつでも見られる。
- 名簿の勇者は、このゲームの中で次のように使う。（決まったこと）
  - **助っ人**: 難しい魔物討伐は学生だけでは行かせられないので、名簿の勇者が先輩・講師として付いてくる。
  - **新入生への影響**: 有名な勇者が出ると知名度が上がり、その勇者に憧れて入学してくる生徒が出る。
  - **書き出し**: ファイルに書き出し・読み込みができる。別のセーブに移したり、友達と交換したりできる。
- 書き出す中身（案）: 名前・職業・能力・覚えた技・実績・卒業年・学園名・形式の版
- 形式は JSON にし、あとで中身が変わっても読めるように版を付ける。（案）
- 助っ人は討伐ならいつでも呼べる。回数の制限はなく、強い勇者ほど予定が合いにくい（決まったこと）
  - 討伐のたびに、名簿の中で **予定が空いている勇者** が決まり、その中から選んで呼ぶ（決まったこと）
  - 強い勇者・有名な勇者ほど予定が空いていることが少ない。（案）
  - 来てくれる助っ人は 1 人まで（生徒 4 人＋助っ人 1 人）。（案）

## 10. セーブ
